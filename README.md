# Bluestock Mutual Fund Analytics

Full-stack Mutual Fund Analytics Platform using Indian mutual fund data from AMFI India and mfapi.in.

## Project Structure

```
bluestock_mf_capstone/
├── data/
│   ├── raw/           ← Original downloaded CSVs
│   ├── processed/     ← Cleaned, merged CSVs + computed metrics
│   ├── powerbi/       ← Power BI-optimised CSV exports
│   └── db/            ← bluestock_mf.db (SQLite star schema)
├── notebooks/
│   ├── 01_data_ingestion.ipynb
│   ├── 02_data_cleaning.ipynb
│   ├── 03_eda_analysis.ipynb        ← 10-task EDA with publication charts
│   ├── 04_performance_analytics.ipynb  ← Sharpe, VaR, Scorecard
│   └── 05_advanced_analytics.ipynb     ← VaR deep dive, Cohort, Recommender
├── scripts/
│   ├── etl_pipeline.py      ← D1: Full ETL (CSV → SQLite)
│   ├── live_nav_fetch.py    ← B1: Live NAV fetcher (mfapi.in)
│   ├── compute_metrics.py   ← D4: CLI risk/performance calculator
│   ├── recommender.py       ← D6: Fund recommender engine
│   └── email_report.py      ← B5: Weekly email report generator
├── sql/
│   ├── schema.sql           ← D2: Star schema DDL
│   └── queries.sql          ← 10 analytical queries
├── dashboard/
│   ├── bluestock_mf.pbix    ← D5: Power BI dashboard (4 pages)
│   └── app.py               ← B2: Streamlit web app
├── reports/
│   ├── Final_Report.pdf     ← D7: Professional report
│   ├── Presentation.pptx    ← D7: Slide deck
│   └── *.png / *.md         ← Charts, build guide, dictionary
└── requirements.txt
```

## Quick Start

```bash
pip install -r requirements.txt
python scripts/etl_pipeline.py              # Load all data
python scripts/compute_metrics.py --all-funds --output data/processed/all_metrics.csv
python scripts/recommender.py --all-profiles
streamlit run dashboard/app.py              # Launch web app
```

## Methodology Notes

- CAGR annualised with **252 trading days** (not calendar days)
- NAV gaps filled with **ffill()** after reindexing to full date range
- AUM columns include **units** in names (`_crore`, `_lakh_crore`)
- All paths use **pathlib.Path** (no hardcoded strings)
- `.db` files are in `.gitignore`; share `schema.sql` instead
